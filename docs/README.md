## Orden sugerido

Validar primero el usuario objetivo y alcance del MVP; luego confirmar reglas de negocio; después cerrar arquitectura y lineamientos tecnológicos. El roadmap debe reflejar esas decisiones. Revisar estos documentos cuando cambien los requisitos o se obtenga retroalimentación de usuarios.
